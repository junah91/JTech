# 🚀 Futuristic Profile Dashboard

A visually striking, futuristic-themed personal profile dashboard built using **HTML**, **CSS**, and **JavaScript**. This project features a responsive sidebar, user profile with avatar upload and local image storage, animated activity stats, and a neon-styled UI — all built without any frameworks.

## 🧩 Features

- 🚪 Sidebar navigation with smooth hover effects  
- 🧍‍♂️ User Profile section with:
  - Editable information
  - Avatar upload with persistent `localStorage` storage
- 🔄 Responsive design (mobile + desktop)
- 📊 Circular stats + animated activity graph
- 🧬 Neon futuristic styling using Orbitron font
